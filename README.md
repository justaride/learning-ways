# Learning Ways

En læringsmakker som hjelper elever å tenke selv, i stedet for å gi dem svaret.

Bygger videre på en prototype laget på Claude Impact Lab, Mesh Oslo, 21. oktober 2026. Learning Ways utvikles videre som et eget prosjekt i [vårt repo](https://github.com/justaride/learning-ways).

## Idé

Ida (13 år, oppdiktet elev) får hjelp med matte uten å få fasit:

- **Hintstigen**: spørsmål → tips → eksempel. Ida svarer Makker med tale eller tekst, og Makker leder videre med spørsmål.
- **Lær bort til Makker**: når Ida har løst oppgaven, har Makker misforstått, og Ida må forklare.
- **Forelderkort**: forelderen ser hvordan Ida jobber (hint brukt, hva hun har forklart) og får en samtalestarter til middagen, ikke hele samtalen.

## Kjør

Åpne `index.html` i Google Chrome. Ingen installasjon, ingen server.

- Tale inn (Snakk-knappen) virker i Google Chrome og Edge.
- Opplesning krever en norsk stemme på maskinen (f.eks. Nora på Mac).
- Lokalt svarer Makker med forhåndsskrevne svar. Som publisert Claude-artefakt svarer ekte Claude.

All data er oppdiktet.
